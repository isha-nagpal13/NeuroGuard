# NeuroGuard

AI-Powered Brain-Computer Interface (BCI) for Real-Time Seizure Prediction and Monitoring.

## Features

* Real-time EEG signal visualization
* Machine Learning-based seizure prediction
* FastAPI backend for inference and analytics
* Interactive patient monitoring dashboard
* EEG CSV upload and automated analysis
* Risk assessment and alert generation
* Healthcare-focused AI application

## Tech Stack

### Frontend

* React.js
* JavaScript
* Vite

### Backend

* FastAPI
* Python

### Machine Learning

* Scikit-Learn
* XGBoost
* Pandas
* NumPy
